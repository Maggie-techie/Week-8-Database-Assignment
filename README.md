# Week-8-Database-Assignment
# Clinic Booking System 

# Description
A full-featured relational database system designed for managing patient records, doctor profiles, appointments, treatments, and payments for a medical clinic.

This project uses MySQL to demonstrate relational database design, complete with relationships, constraints, and entity integrity.

# Features
- Patient records management
- Doctor profiles and specialization tracking
- Appointment scheduling and status updates
- Treatment record keeping
- Payment tracking
- Doctor shift management (many-to-many relationship)
